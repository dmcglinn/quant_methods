Below are homework assignments that accompany the core lessons of the course.
Homework should be turned in on OAKS (https://lms.cofc.edu) in the appropriate dropbox folder. 

**Turn both your code (.R or .Rmd file) and your compiled product as either a pdf
or word doc file.** Unfortunately, OAKS strips html files of their graphics when 
they are uploaded to dropbox folder and therefore that file format is not 
appropriate. If you are unsure or unable to compile your code then at a minimum 
upload your script file. See the [lesson on Rmarkdown](./lessons/rmarkdown_notes.md) for more information about
how to compile code.
